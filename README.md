A Machine Learning-powered Spam Detection API built with Python, XGBoost, TF-IDF Vectorization, and FastAPI. This project classifies text messages as Spam or Not Spam through a REST API.

Features
Detects spam messages using Machine Learning.
Trained using an XGBoost classifier.
Uses TF-IDF Vectorizer for text preprocessing.
RESTful API built with FastAPI.
Interactive API documentation with Swagger UI.
Easy to deploy on Render, Railway, or any cloud platform.
